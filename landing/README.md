# Logivo Landing

Публичный лендинг платформы Logivo. Визуальная система продолжает дизайн мобильного приложения: тёмный графитовый фон, бирюзовые акценты, интерактивные экраны и плавные анимации.

## Локальный запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://localhost:4175](http://localhost:4175).

## Production-сборка

```bash
npm run build
npm run preview
```

Готовые статические файлы будут в папке `dist`.
